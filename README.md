# 법조인 키우기: 로스쿨 서바이벌

구글 플레이: https://play.google.com/store/apps/details?id=com.kimseongho.lawyergame

이 사이트는 스토어 안내·개인정보 처리방침·사업자 정보만 둡니다. 테스트 버전(웹·APK)은 2026-10-24 정식 출시로 닫았습니다.
- `privacy.html`, `business.html`: 플레이 콘솔과 게임 안에서 링크하므로 지우거나 옮기지 말 것
- `sw.js`: 예전 테스트 웹을 설치한 기기의 오프라인 캐시를 지우는 용도
- `version.json`: 예전 테스트 앱이 이 파일을 보고 「새 버전」 안내 → 이 안내 페이지로 온다
- `notice.json`: 정식 앱(1.0.1~)이 타이틀에 띄우는 공지. `{"id": "바꿀 때마다 새 값", "text": "200자 이내", "until": "2026-11-30"(선택), "url": "https://…"(선택)}` · 비우면(`"id": ""`) 안 뜸
- `privacy-20261019.html`: 이전 개인정보 처리방침 (변경 이력 열람용)

안드로이드 앱 받기 (APK)

약 15MB · 와이파이에서 받는 걸 추천해요

설치 방법
  1. 위 버튼을 눌러 받습니다. 「유해할 수 있는 파일」 경고가 뜨면 그래도 다운로드.
  2. 다운로드가 끝나면 알림이나 「내 파일 → 다운로드」에서 lawyer-game.apk를 엽니다.
  3. 「출처를 알 수 없는 앱」 허용 화면이 나오면 Chrome(또는 내 파일)에 허용을 켜고 뒤로 돌아와 설치.
  4. Play 프로텍트가 「확인되지 않은 앱」이라고 하면 세부정보 → 무시하고 설치. (스토어에 올리기 전 테스트 버전이라 그래요)
알아 두세요
  1. 새 버전이 나오면 같은 방법으로 받아 덮어 설치하면 진행이 그대로 남습니다. 앱을 지우면 진행도 지워져요.
  2. 테스트 버전이라 상점의 결제는 실제로 돈이 나가지 않고 바로 지급됩니다.
  3. 버그는 게임 안 메뉴 → 설정 → 「제보 보내기」로 보내 주세요.
  4. 아이폰은 아직 앱이 없어요. 웹으로 하기 → 사파리 공유 → 「홈 화면에 추가」.
